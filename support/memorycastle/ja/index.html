Memory Castle について

Memory Castle は、記憶の達人たちが使う古代の技法「場所法（記憶の宮殿）」をもとにした、iPhone・iPad向けの記憶ゲームです。手描きの20の部屋を歩き、どこに何が置かれているかを覚えたら、記憶を頼りに部屋を再現しましょう。ストーリーモードの部屋1〜3は無料。それ以外は小さな買い切りの購入で解放できます。広告もサブスクリプションもありません。

遊び方

各部屋には、いくつかのアイテムがそれぞれ決まった場所に置かれています。どこに何があるかを覚えたら、部屋は空になります。トレイからアイテムをドラッグして、元のリングに戻してください。すべてのアイテムを正しい場所に戻せば、その部屋はクリアです。

「簡単」「普通」「難しい」で、1部屋のアイテム数が4・5・6個に変わります。難易度はモードごとに選べます。

3つのモード

  • ストーリーモード — 全20部屋。部屋のアイテムは、レベルが上がるごとに1つずつ増えていきます。3部屋クリアするごとに門番が現れ、その3部屋すべてをヒントなしで再現するよう求めてきます。1回ミスしても、もう一度だけ挑戦できます。もう一度ミスすると、そのエリアの最初の部屋まで戻ります。門を通過すると、そこまでの道のりが難易度ごとに保存されます。「地図を表示」をタップすれば、到達済みのどの部屋からでも始め直せます。
  • タイムアタックモード — どの部屋も最初からすべてのアイテムがそろった状態で登場し、アイテムは1個あたり1〜7秒で設定したタイマーに合わせて1つずつ現れます。ここでも3部屋ごとに門番が現れ、一度でもミスするとランはそこで終わりです。
  • エンドレスモード — 部屋は次々と現れ、1部屋クリアするたびに、それまでクリアしたすべての部屋を再現します。一度でもミスすると、ランはそこで終わり。どこまで深く進めたかがスコアになります。

購入

ストーリーモードの部屋1〜3は無料です。それ以外はすべて買い切りで、サブスクリプションも広告もありません。

  • すべての部屋 — すべてのモードで部屋4〜20を解放
  • エンドレスモード — エンドレスモードを解放
  • タイムアタックモード — タイムアタックモードを解放
  • オールアクセス — すべてを解放
  • 城をコンプリート — 上の3つのアイテムのうちちょうど1つを持っている場合に表示され、残りをすべて解放

購入の処理は Apple が行います。新しい端末やリセットした端末で購入を取り戻すには、ゲーム内ストア画面または「設定 ▸ 購入履歴」の「購入を復元」をタップしてください。

設定

  • 言語 — 英語、フランス語、イタリア語、ドイツ語、スペイン語、ポルトガル語（ブラジル）、日本語、韓国語、簡体字中国語から選べます。再起動なしで、すぐに切り替わります。
  • BGMと効果音 — それぞれオン／オフでき、プレイ中に流れる曲も選べます（「シャッフル」も可）。
  • 遊び方 — チュートリアルをいつでも見直せます。
  • 進行状況をリセット — このデバイスの自己ベストと、ストーリーモードで保存された道のりを消去します。購入内容はそのまま残ります。
  • クレジット — BGMと効果音は Gemini で作成されています。

トラブルシューティング

メールを送る前に、次の手順を上から順にお試しください。ほとんどの問題は最初の2つで解決します。

  1. App Store で Memory Castle が最新バージョンになっているか確認する。
  2. アプリを完全に終了してから開き直す。
  3. 端末を再起動する。
  4. iOS／iPadOS が最新か、空き容量が残っているかを確認する。

不具合の報告

それでも直らない場合は、次の情報を添えてメールでお知らせください。

  • 端末のモデル（例：iPhone 14、iPad Air）
  • どのモード・難易度・部屋で起きたか
  • 期待していた動作と、実際に起きたこと
  • 可能であれば、スクリーンショットか画面収録

どの部屋も、正しい配置はひとつだけです。だからもし、確かに正しく置いたはずのアイテムが数えられなかったなら、本当の原因はたいていその細部に隠れています。報告が具体的であるほど、修正も早くなります。

よくある質問

購入したのに、ロックされたままです。

購入時と同じ Apple Account でサインインした状態で、「購入を復元」（ゲーム内ストア画面、または「設定 ▸ 購入履歴」）をタップしてください。復元に料金はかかりません。それでもロックされたままなら、アプリを完全に終了してから開き直してください。

先の部屋から始めるには？

ストーリーモードで「地図を表示」をタップしてください。到達済みのどの部屋からでも始め直せます。道のりは門を通過するたびに、難易度ごとに保存されます。

インターネット接続は必要ですか？

いいえ。Memory Castle は完全オフラインで遊べます。アカウントもログインも不要です。（購入や購入の復元は App Store を通して行うため、その瞬間だけ通信が必要です。）

進行状況は保存されますか？

はい。保存された道のり、自己ベスト、設定は端末内に保存されます。アカウントは存在しないため、サーバーへのバックアップはありません。アプリを削除すると、これらも削除されます。

対応端末は？

iOS 18 以降の iPhone と iPad に対応しています。折りたたみ式 iPhone でも、閉じても開いても遊べます。

部屋や機能のリクエストはできますか？

もちろんです。メールでお送りください。小さくて具体的な提案ほど、実現しやすくなります。

それでも解決しないときは

いつでもご連絡ください。すべてのメールに自分で目を通し、できるだけ早くお返事します。
